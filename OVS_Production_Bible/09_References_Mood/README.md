# 09 — References & Mood

**What lives here:** Visual and tonal inspiration organized for fast access during production.

- Film stills and frame grabs (organized by director / film)
- Mood boards (one per project or tonal category)
- Photography references (Gordon Parks, Richard Avedon, Diane Arbus, William Eggleston)
- Trailer clips and links index
- Inspiration screenshots — social media, editorial, advertising

**Naming convention:** `[source]_[description]_[date].[ext]` — e.g. `fincher_se7en_interrogation_ref.jpg`

**Rule:** These are reference materials only. Do not store licensed assets here without clearance documentation in `11_Business_Ops/`.
