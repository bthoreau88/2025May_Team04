## Scene: [Scene # — Description]

### LENS
```
[focal length] [framing], [camera movement]
```
> e.g. `85mm medium close-up, locked camera`

### SUBJECT
```
[age/gender], [physical descriptors], [clothing]
```
> e.g. `A man in his mid-40s, lean jaw, dark wool suit, white shirt open at collar`

### ACTION / STATE
```
[what they're doing or how they exist in the frame]
```
> e.g. `standing at a window, not looking out, cigarette burning in right hand`

### ENVIRONMENT
```
[location], [era], [time of day / weather], [ambient light state]
```
> e.g. `late 1960s motel room, overcast daylight through thin curtains, one practical lamp on`

### LIGHTING
```
[dominant source + color temp], [secondary source], [shadow quality]
```
> e.g. `practical warm amber dominant, cold window secondary, hard wall shadow`

### GRADE / TEXTURE
```
[film stock / grain], [black point], [color character]
```
> e.g. `35mm grain visible, crushed blacks, muted warm palette, slight green shadow push`

### REFERENCE VECTOR
```
visual register of [film title], [DP or photographer]
```
> e.g. `visual register of No Country for Old Men, Roger Deakins`
