# 08 — Templates

**What lives here:** Starter documents for every stage of the OVS pipeline.

| File | Stage | Use |
|---|---|---|
| `brief_template.md` | BRIEF | One-page project intake |
| `treatment_template.md` | TREATMENT | Scene-by-scene narrative |
| `shot_list_template.md` | SHOT LIST | Shot-by-shot craft plan |
| `prompt_builder_starter.md` | PROMPT BATCH | OVS anatomy prefilled |
| `pitch_deck_template.md` | PITCH | Slides structure for external presentation |

**Rule:** Copy templates into the project folder — never edit originals in place.

**See also:** PRODUCTION_BIBLE.md §10 (Project Pipeline)
