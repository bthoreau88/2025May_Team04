# 11 — Business Operations

**What lives here:** Everything that keeps OVS functioning as a studio entity.

- Release strategy document (platforms, cadence, audience targeting)
- Platform accounts index (usernames, handles, login notes)
- Contacts directory (collaborators, vendors, platforms)
- Contracts and agreements folder
- Distribution notes (rights, territories, exclusivity windows)
- Asset clearance documentation
- Budget tracking (per project)
- Press / media materials

**Sensitivity note:** This folder may contain confidential information. Do not sync to shared or public repositories without review.
