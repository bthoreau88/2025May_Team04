# OVS Proven Prompt Modules

Battle-tested fragments. Drop into any prompt — mix and match. Organized by element.

---

## LENS MODULES

```
85mm medium close-up, locked camera
```
*The OVS default. Intimate but not crowded.*

```
85mm medium close-up, slow rack focus from hands to face
```
*Reveals interiority. Use for the moment a character decides something.*

```
40mm medium wide, slow push in over 8 seconds
```
*Creates dread through accumulation. Use for establishing tension.*

```
135mm telephoto, stationary, subject small in frame, city behind
```
*Isolation. The world continuing without caring.*

```
21mm wide establishing, locked, subject entering frame from right
```
*Scale and arrival. Use for location establishes and reveals.*

```
50mm eye-level locked, subject dead center frame
```
*The confrontation shot. Direct and unnerving.*

## SUBJECT MODULES

### Stylish Protagonist (Male)
```
A man in his mid-40s, lean jaw, watchful eyes, dark wool suit slightly worn at the elbows, 
white dress shirt open at the collar, no tie
```

### Stylish Protagonist (Female)
```
A woman in her late 30s, composed expression, slight tension in the jaw, dark fitted coat, 
hair back, a single piece of jewelry that doesn't quite match the rest
```

### The Antagonist
```
A man in his 50s, well-fed, completely at ease, dressed better than the room requires, 
pleasant expression that never quite reaches the eyes
```

### The Witness
```
A person of indeterminate age in an institutional uniform — janitor, waitress, orderly — 
moving through the background, not looking at the camera, not looking at the subject
```

### The Child (Uncanny)
```
A child, 8–10 years old, very still, watching something off-frame, dressed in clothes 
slightly too formal for the setting, completely clean
```

## ENVIRONMENT MODULES

### Motel Room (Night)
```
a motel room, late 1960s, one bedside lamp on, thin curtains closed, dark parking lot 
light bleeding through the gap, wood-panel walls, orange bedspread
```

### Roadside Diner (Night)
```
interior of a roadside diner, 1970s, fluorescent overhead, red vinyl booths, mostly empty, 
rain on the plate glass window, a coffee counter with one other patron
```

### Exterior Parking Lot (Night)
```
a commercial parking lot, 1970s, night, sodium vapor lamp overhead casting orange pool, 
one car in frame, chain-link fence at the edge of light, rain-slicked asphalt
```

### Inside the Cadillac
```
interior of a 1966 Cadillac DeVille, moving, night, dashboard glow amber, headlights 
illuminating road signs, windshield wipers, radio playing low
```

### Exterior — The Cadillac Parked
```
a black 1966 Cadillac DeVille parked under a sodium vapor streetlamp, night, light rain, 
polished but aged, engine off, driver's side window slightly open
```

### Rural Road (Night)
```
a two-lane rural highway, night, no other cars, tree line both sides, centerline 
disappearing into darkness, headlights the only source
```

### Empty Office (Institutional)
```
a government or institutional office, late 1970s, fluorescent overhead one tube flickering, 
metal desks, a dropped ceiling, linoleum floor, one window with a view of another brick wall
```

## LIGHTING MODULES

### Practical Lamp (Warm)
```
single practical table lamp, tungsten warm, hard shadow on wall behind subject, 
no fill, deep shadow on the unlit side of the face
```

### Neon Sign (Exterior)
```
neon sign as key light, red-orange cast, intermittent flicker, rain-wet surface 
reflecting the color, deep shadow beyond the sign's reach
```

### Bare Bulb (Interrogation)
```
single bare incandescent bulb overhead, hard downward light, deep under-eye shadows, 
subject half in and half out of the circle of light
```

### Window Light (Cold)
```
overcast daylight through a single window, flat and cold, no fill, subject positioned 
so the light catches half the face and loses the other
```

### Headlights
```
headlights as primary source, cold white, subject caught in the beam, hard shadow 
stretching back, everything beyond the headlight reach in total darkness
```

### Fluorescent (Institutional Dread)
```
overhead fluorescent, one tube slightly flickering, flat unflattering light, 
green color shift in the shadows, no warmth anywhere in frame
```

## GRADE / TEXTURE MODULES

```
35mm grain visible, crushed blacks, muted warm palette, slight green shadow push
```
*The OVS default grade.*

```
35mm grain heavy, blown highlights, high contrast, desaturated to near-monochrome
```
*For pieces at maximum Fincher.*

```
16mm grain heavy, warm midtones, heavy vignette, soft focus on edges
```
*More intimate, slightly more vulnerable — use for Peele-heavy pieces.*

```
35mm fine grain, amber midtone, pulled-down highlights, teal-shadow grade
```
*The "good cinema" look — for A24-heavy pieces.*

```
overexposed 35mm, bleach bypass, silver retention, cold desaturated
```
*Maximum alienation. Use sparingly.*

## MOVEMENT MODULES

```
camera locked, subject moves through frame
```
*The world is still. Something enters it.*

```
barely perceptible push in over the scene, maybe 3–4 inches total
```
*The audience feels something tightening without knowing why.*

```
handheld — subtle, breathing, not aggressive — follows subject at 85mm
```
*Used only for intimacy or disorientation. Not a default.*

```
rack focus from background threat to foreground subject in 2 seconds
```
*The reveal of what they don't know is behind them.*
