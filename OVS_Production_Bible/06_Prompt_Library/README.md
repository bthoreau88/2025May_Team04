# 06 — Prompt Library

**What lives here:** All Seedance 2.0 prompt materials and reusable modules.

- `prompt_anatomy.md` — the OVS prompt structure reference (lens → subject → action → lighting → grade → reference vector → negative)
- `negative_prompts_master.md` — the full standard negative prompt block
- `proven_modules.md` — battle-tested prompt fragments, organized by element
- `video_prompt_builder.md` — fill-in-the-blank prompt scaffolds
- Per-project prompt batches (one `.md` per scene, named `[project]_s[scene#]_[description].md`)

**Naming convention:** `[project_slug]_s01_exterior_motel.md`

**See also:** PRODUCTION_BIBLE.md §8 (The OVS Prompt Anatomy) and §9 (Standard Negative Prompts)
