# 10 — Assets

**What lives here:** Production-ready and cleared assets for use in OVS work.

```
logos/          ← OVS logo variants (all formats)
fonts/          ← Licensed typefaces used in OVS titles/graphics
music_beds/     ← Licensed or original score beds
sfx/            ← Sound effect library
generated_stills/ ← Keeper stills from generation runs
b_roll/         ← Supplemental footage
```

**Rule:** Everything in this folder should be cleared for the intended use. See `11_Business_Ops/` for clearance docs.

**Generated stills naming:** `[project_slug]_[scene#]_[take#]_[brief_description].jpg`
e.g. `motel_01_s03_t02_exterior_night_rain.jpg`
