# 00 — Brand Identity

**What lives here:** Everything that defines OVS as a studio entity.

- Studio name origin and rationale ("Omnia Vanitas" — All is Vanity)
- Logo files (primary, secondary, wordmark, reversed)
- Mission statement (long form, short form, one-liner)
- Brand tagline(s)
- Voice & tone guidelines — how OVS writes, speaks, and presents itself
- What OVS does not say (off-brand language list)

**Naming convention:** `ovs_logo_[variant]_[color].[ext]` — e.g. `ovs_logo_primary_dark.svg`
